# tests — Übergreifende Tests

- `e2e/` — End-to-End über mehrere Komponenten (z. B. Phase-1-Pipeline Upload bis Protokoll; Latenz-Messskript Phase 2).
- `unit/` — übergreifende Unit-Tests, die nicht an eine einzelne App gebunden sind.

App-spezifische Tests liegen bei der App (apps/backend/tests, apps/web/tests). Test zuerst (RED) vor Implementierung.
